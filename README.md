# Go Interface Lab

Deep exploration of Go interfaces, dependency inversion, mocking, polymorphism, clean architecture, repositories, services, testing patterns, and real-world backend design.

---

# Purpose

This repository is not a collection of random syntax examples.

The goal is to develop production-level understanding of Go interfaces and how they are used in scalable backend systems.

Topics are explored progressively from:
- beginner mental models
- to architectural reasoning
- to professional backend engineering patterns

This repository focuses on:
- understanding WHY interfaces exist
- solving coupling problems
- designing scalable systems
- building testable applications
- writing idiomatic Go

---

# Learning Objectives

By the end of this repository, the goal is to understand:

- implicit interface implementation
- polymorphism in Go
- method sets
- pointer vs value receivers
- dependency inversion
- repository pattern
- service abstractions
- mocking and testing
- interface composition
- type assertions and switches
- nil interface edge cases
- runtime behavior of interfaces
- clean architecture patterns
- when NOT to use interfaces
- common Go interface anti-patterns
